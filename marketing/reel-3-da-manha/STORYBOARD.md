# Reel 3: "Aberto às 3 da manhã"

1080x1920, 30 fps, 12.0 s (360 f), clock smooth, smear on type and notifications only. No sound. Approved plan: the "Roteiros 3D CODE SITE" deck, Reel 3.

## PAGE
- **Problem:** a shop without a site only sells while it is open.
- **Audience:** small retailers on Instagram.
- **Goal:** they message CODE SITE on WhatsApp about an online store.
- **Emotion:** "I could be selling right now".
- **The one true thing:** CODE SITE builds online stores with catalogue, checkout and Pix (Services: E-commerce).

## Idea
The phone is the cause and a paper bag in 3D is the effect, cut against each other:
- An order notification rolls up on a lock screen at 3:14.
- In the next shot, a package falls into the bag.
- After three orders the light turns to morning.

The store "lua." and its orders are fictional and illustrative, like BRASA 41.

**Accent:** moon gold for the store's own icon; CODE SITE blue only on "dorme." in the CTA.

## World
- **Night:** a blue room with a window glow, a dark counter, cold key and rim light, and hard shadows from the key.
- **Morning:** warm sun from the same window side, a warm counter, and the bag full.
- **Phone:** a magnified native-ui lock screen (scale 2.75, a notification is 1015 px wide), its notifications moved under the clock.
- **CTA:** CODE SITE paper.
- **Hero moment:** the full bag in the first morning light.
