# Reel: "Esse hambúrguer não é foto"

1080x1920, 30 fps, 13.0 s (390 f), clock smooth, blur grammar = per-element smear on type only. No voice or music (no ElevenLabs key): the owner adds a trending Instagram sound on top.

## PAGE
- **Problem:** small businesses lose customers who search before they buy and find no site, or a site that looks like everybody's template.
- **Audience:** owners of small Brazilian businesses scrolling Reels (Curitiba area, WhatsApp-first).
- **Goal:** they message CODE SITE on WhatsApp, (41) 98430-3059.
- **Emotion:** "wait, that's a website?" then "I want one like that".
- **The one true thing:** CODE SITE wrote the BRASA 41 landing from scratch, including a real-time 3D burger. The burger in the film is that code (concepts/brasa41/burger3d.js), rendered live, not a photo or a stock 3D model.

## Ideas considered
1. **Not a photo (chosen).** A burger held like a product shot; it turns (a photo can't), then comes apart while the real functions that draw each layer are typed, then lands inside the BRASA 41 site on a phone, and the site's own "Pedir agora" press cuts to the CTA. Cover-the-logo: the code on screen is CODE SITE's own source and the site is its own work, so a competitor can't run this film.
2. Search documentary: someone types "hamburgueria perto de mim" and only one result has a real site. Needs an invented search UI (generic web component) and proves less.
3. Typographic essay on "Instagram não é site". Type-only films lost to films with the brand's own picture (edits.md).

## World
- **Acts 1-3 (burger, code, phone):** BRASA's coal ground #0e0b09 lit from behind the hero by a warm pool, floor shadow from the real 3D key light, film grain, a few embers drifting (BRASA's own hero motif). One world: the phone sits in it.
- **Act 4 (CTA):** CODE SITE's paper ground with a soft top light and grain: the brand switch is the point of the cut (BRASA's site -> yours).
- **Hero moment (screenshot-worthy):** the burger mid-unstacking, `makeTomatoes()` typed above it, the layers fanned in warm light.
