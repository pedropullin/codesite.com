# Reel 1: "Do código ao ar"

1080x1920, 30 fps, 12.0 s (360 f), clock smooth, smear on type only. No sound (the owner adds an Instagram sound). Approved plan: the "Roteiros 3D CODE SITE" deck, Reel 1.

## PAGE
- **Problem:** people think a site is a template filled in, not something built.
- **Audience:** small business owners on Instagram.
- **Goal:** they message CODE SITE on WhatsApp.
- **Emotion:** "it's made from scratch, and fast".
- **The one true thing:** CODE SITE's own process, the four steps on codesite.online ("Quatro commits até o ar": `git init`, `design --figma`, `npm run build`, `deploy --prod`), ending in the live codesite.online.

## Idea
The CODE SITE mark is assembled in 3D by its own process. Each command typed is answered by one part of the mark, and the last one flips the mark into a phone showing codesite.online. Cover-the-logo test: the mark, the commands and the site are all CODE SITE's own.

**Accent:** blue means code (the flags `--figma` / `--prod`, "no ar?") and the slash of the mark.

## World
- **Acts 1-3:** ink ground with a cold blue light pool behind the hero, the studio environment reflecting in black lacquer, and a floor shadow.
- **Act 4:** CODE SITE's paper ground, as in the burger Reel. The series keeps one CTA.
- **Hero moment:** the blue slash crashing into the lacquer tile.
