# Reel 2: "Igual a todo mundo"

1080x1920, 30 fps, 12.0 s (360 f), clock smooth, smear on type only. No sound. Approved plan: the "Roteiros 3D CODE SITE" deck, Reel 2.

## PAGE
- **Problem:** template sites make every business look the same.
- **Audience:** small business owners on Instagram.
- **Goal:** they message CODE SITE on WhatsApp.
- **Emotion:** "mine looks like that", then "I want mine to stand out".
- **The one true thing:** CODE SITE builds from scratch ("Nada de template pronto"), and the BRASA 41 burger is a piece it made.

## Idea
A corridor of identical grey template sites. One leaves the grid, spins, and a match cut on the spin turns it into the BRASA 41 burger in colour and warm light, while the grey field dims behind it. The template is drawn as a generic wireframe on purpose: it is the anti-example, not a real site.

**Accent:** blue = made from scratch, used only on "do zero?".

## World
- **Template act:** a grey fog world, cold ceiling light, hard floor shadows, and a dark ceiling of fog so the type reads.
- **Burger act:** BRASA's coal and ember light comes in at the match cut.
- **CTA:** CODE SITE's paper ground (the series' CTA).
- **Hero moment:** the coloured burger hovering over the dimmed grey grid.
