# NOTE: "Igual a todo mundo" (Reel 2 of the 3D series, 12 s)

`final.mp4`: 1080x1920, 30 fps, 360 frames, no audio. Source: `index.html`; plan in `STORYBOARD.md` and in the deck "Roteiros 3D CODE SITE", Reel 2.

## Idea
- A corridor of identical grey template sites.
- They all light up the same way at the same moment.
- One leaves the grid and spins, and a match cut on the spin turns it into the BRASA 41 burger in colour and warm light, while the grey field dims.
- Copy: "Seu site é igual a esse?", then "Template deixa todo mundo igual.", then "Do zero, com a sua cara."

## Real and illustrative
- **Real:** the burger is the BRASA 41 code (`burger-kit.js`, shared with the burger Reel). The number and the mark are CODE SITE's.
- **Illustrative:** the template slab is a generic wireframe drawn on purpose as the anti-example. It is not a real site or anyone's product.
- **Not used:** no generated images, no sound.
